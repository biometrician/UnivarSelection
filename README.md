# Univariable selection: web extras

This repository includes the code and materials needed to reproduce the analysis and web extras of

> Ullmann T., Heinze G., Kappenberg F., Henrion M., Sauerbrei W., Collins G., Leonhardt C.-S., Nold M., and Dunkler D., for TG2 of the STRATOS initiative (2026).
> *The Problem with Univariable Selection in Regression Modelling — and What To Do Instead.*
> Manuscript in preparation.

## Contents

### Interactive Shiny app

The [`shiny_app`](shiny_app/) folder contains the R code for the interactive Shiny app referenced in **Box 3: An interactive tool to explore consequences of univariable selection**.

The app allows users to explore the consequences of applying univariable preselection in regression modelling under different data-generating scenarios.

**Online app:**
https://biometrician.shinyapps.io/UnivarSelection/

---

### Web extra: Commented analyses of two real-world studies

The [`web_extra_w1`](web_extra_w1/) folder contains the Quarto source files and R code for **Web extra: Commented analyses of two real-world studies**.

The web extra presents reproducible analyses of two real-world case studies and contrasts modelling strategies appropriate to the respective research objectives with univariable selection.

**Online web extra:**
https://biometrician.github.io/UnivarSelection/

---

### Code to reproduce the simple simulation

The [`simple_simu`](simple_simu/) folder contains the R code to reproduce the results of the simple simulation, which are reported in the subchapter *Demonstrating the problems: a simple simulation* of the manuscript.

---

## Reproducibility

The code and materials in this repository are provided to support the reproducibility and transparency of the analyses presented in the paper and its web extras.
